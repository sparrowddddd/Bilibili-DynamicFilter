# 功能
- ☑️把简介、评论、视频推荐（分P、合集）做成Tab放到播放器右侧，省去下翻操作
- ☑️up信息、视频信息统一放到视频下方
- ☑️评论区可调节字体大小、一键回到最顶部
- ☑️发表评论、视频分P、合集可以展开和收起
- ☑️可设置默认显示的Tab

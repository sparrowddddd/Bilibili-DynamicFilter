# 功能
- ☑️动态可根据自己的分组进行筛选，原理是先加载全部的动态然后分配到各个分组里，所以如果关注过多，人少的分组可能加载很慢
- ☑️优化界面，
- ☑️评论区可调节字体大小、一键回到最顶部
- ☑️发表评论、视频分P、合集可以展开和收起
- ☑️可设置默认显示的Tab
